# Security Policy

Tech It More is a static website with no accounts, payments, backend or stored user data. Saved lists and preferences stay in each visitor's own browser. Even so, I take security reports seriously.

## Supported versions

Only the latest version on the `main` branch, which is the live site at https://tech-it-more-gaming-catalog.pages.dev, is supported.

| Version             | Supported |
| ------------------- | --------- |
| Latest (`main`)     | Yes       |
| Older commits       | No        |

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe what you found, the steps to reproduce it, and the impact you think it has.

What to include if you can:
- The page or file affected
- Steps to reproduce, or a short proof of concept
- Your browser and device

## What to expect

- I'll acknowledge your report within **7 days**.
- I'll keep you updated while I investigate and fix it.
- Once fixed, I'm happy to credit you if you'd like.

## In scope

- Cross-site scripting (XSS) or content injection on the site
- Weaknesses in the security headers or Content Security Policy
- Secrets or private data accidentally committed to this repository
- Broken or malicious outbound links

## Out of scope

- Missing prices, stock or product details (the site doesn't show them by design)
- Problems on third-party retailer sites that the catalog links to
- Reports that need physical access to someone's device
- Automated scanner output with no demonstrated impact

Thank you for helping keep Tech It More safe.
